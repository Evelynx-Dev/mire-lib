# Changelog

All notable changes to the mire standard library.

## [0.0.1] - 2026-07-21

### Added

- `mire::vec` — vector operations: push, push_i64, pop, get, set, remove, clear, concat, sort, reverse, contains, index, slice, flatten, unique, len
- `mire::map` — map/dict operations: get, get_i64, set, has, keys, values, count, remove, merge, len
- `mire::str` — string operations: len, upper, lower, trim, replace, contains, startswith, endswith, split, join, substr, repeat, index, from_i64, to_i64
- `mire::io` — I/O: print, println, input, input_prompt
